# BMW Sales Performance Analysis Using Power BI (2010–2024)

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze BMW sales performance from 2010 to 2024. The dashboard provides insights into sales trends, regional performance, pricing patterns, and key factors influencing sales, enabling data-driven business decision-making.

**Project Type:** Group Academic Project

---

## Dataset Information

- **Time Period:** 2010–2024  
- **Total Records:** 50,000  
- **Key Variables:**
  - Model
  - Year
  - Region
  - Fuel Type
  - Transmission
  - Engine Size
  - Price (USD)
  - Sales Volume
  - Sales Classification

---

## Data Preparation

The dataset was prepared in Power BI through the following steps:

- Imported dataset into Power BI
- Performed data validation and cleaning
- Handled missing values and inconsistencies
- Corrected data types for analysis
- Created DAX measures for analysis

**Key Measures:**
- Total Sales Volume
- Average Price (USD)

---

## Dashboard Features

### Sales Performance Overview
- Total Sales Volume analysis    
- Regional Revenue comparison  
- Average vehicle price analysis  

### Yearly Performance Analysis
- Revenue trends (2010–2024)  
- Sales volume trends  
- Average price trends  
- Transmission-wise sales comparison  
- Sales classification analysis  
- Interactive filters and slicers  

### Performance Drivers Analysis
- Regional sales comparison  
- Mileage trends over time  
- Sales distribution by color  
- Engine size analysis  
- Key Influencers visual for price drivers
